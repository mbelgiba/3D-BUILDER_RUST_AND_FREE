# Локальный AI-конвейер изображения в 3D

1. Браузер показывает JPEG/PNG и отправляет файл Rust-серверу.
2. Axum проверяет содержимое изображения, ограничения размера и количества пикселей, затем сохраняет его в `uploads/`.
3. Rust запускает локальный `run.py` из TripoSR в отдельном процессе. Модель автоматически загружает веса при первом запуске; дальнейшие запросы используют кэш.
4. Пока Python-модель работает, браузер опрашивает `GET /api/generation/{id}`.
5. TripoSR сохраняет GLB в `generated/{id}/0/mesh.glb`. Rust отдаёт модель через `/api/generation/{id}/model`, а Three.js загружает её в просмотрщик.

Meshy API и ключ не используются. Генерация выполняется на компьютере, где запущен backend: без GPU она может быть медленной. Веса модели и Python-зависимости не входят в Git и устанавливаются отдельно. TripoSR опубликован под лицензией MIT; см. [официальный репозиторий](https://github.com/VAST-AI-Research/TripoSR).
