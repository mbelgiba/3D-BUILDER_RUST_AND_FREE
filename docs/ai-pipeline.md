# Локальный AI-конвейер изображения в 3D

1. Браузер показывает JPEG/PNG и отправляет файл Rust-серверу.
2. Axum проверяет содержимое изображения, ограничения размера и количества пикселей, затем сохраняет его в `uploads/`.
3. Rust запускает локальный `run.py` из TripoSR в отдельном процессе. Модель автоматически загружает веса при первом запуске; дальнейшие запросы используют кэш.
4. Пока Python-модель работает, браузер опрашивает `GET /api/generation/{id}`.
5. TripoSR строит сетку с разрешением 192 и UV-развёртку, затем запекает цветную текстуру размером 2048×2048. Скрипт `ai/embed_texture.py` немного усиливает насыщенность и контраст, после чего встраивает её в непрозрачный PBR-материал GLB. Rust отдаёт готовую модель через `/api/generation/{id}/model`, а Three.js загружает её в просмотрщик.

Текстурирование лучше сохраняет заметные цвета и рисунок исходной фотографии, чем цвет вершин, но не гарантирует точное совпадение: модель восстанавливает объём по одному ракурсу и не знает, как выглядят скрытые стороны. Запекание текстуры добавляет время к генерации. Meshy API и ключ не используются. Генерация выполняется на компьютере, где запущен backend: без GPU она может быть медленной. Веса модели и Python-зависимости не входят в Git и устанавливаются отдельно. TripoSR опубликован под лицензией MIT; см. [официальный репозиторий](https://github.com/VAST-AI-Research/TripoSR).
