# RT Studio

**RT Studio** — локальная веб-студия для создания и редактирования 3D-моделей по фотографии. Приложение объединяет AI-реконструкцию изображения, браузерный редактор сцены и учебный трассировщик лучей, написанный на Rust.

Интерфейс доступен на русском, казахском и английском языках. Проект работает локально: изображение обрабатывается на компьютере, а для генерации не нужны платный облачный API или API-ключ.

## Возможности

- **Изображение → 3D:** локальная модель TripoSR создаёт приблизительную сетку и цветную текстуру, результат открывается как GLB.
- **Редактор сцены:** добавление примитивов, выбор и трансформация объектов, настройка света и материалов, скругление рёбер, сглаживание и каркасный режим.
- **Экспорт и проекты:** экспорт объектов в GLB/OBJ, сохранение сцены в GLB и повторное открытие проекта.
- **Библиотека моделей:** готовые GLB-файлы сохраняются в IndexedDB браузера.
- **Рендер на Rust:** трассировщик строит изображения демонстрационных сцен и сохраняет их в формате PPM.
- **Аккаунт:** серверная регистрация и вход с Argon2-хешированием пароля.

> Реконструкция по одной фотографии приблизительная: изображение не содержит информации о невидимых сторонах объекта. Rust-трассировщик рендерит встроенные сцены из примитивов и пока не рендерит импортированные AI-модели.

## Технологии

- Backend и трассировщик: Rust, Axum, Tokio.
- Интерфейс и 3D-просмотр: TypeScript, Vite, Three.js, WebGL.
- Генерация моделей: TripoSR, Python и PyTorch.
- Форматы: JPEG/PNG на входе, GLB/OBJ для моделей, P3 PPM для рендера.

## Быстрый запуск

Требуются Rust/Cargo, Node.js 20+, npm и браузер с поддержкой WebGL.

```bash
cd frontend
npm install
npm run build
cd ..
cargo run
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). При первом входе создайте профиль.

### Включение генерации по фото

Генерация необязательна: редактор, демонстрационная сцена и Rust-рендер доступны и без TripoSR. Для установки модели и окружения Python выполните из корня репозитория:

```bash
bash scripts/setup-local-ai.sh
```

Установщик требует интернет-соединение и свободное место на диске; веса AI загружаются при первом запуске модели. На CPU генерация может работать медленно. Подробности — в [руководстве по запуску](docs/index.md) и [описании AI-конвейера](docs/ai-pipeline.md).

### Разработка интерфейса

Запустите Rust-сервер командой `cargo run`, затем во втором терминале:

```bash
cd frontend
npm run dev
```

Vite выведет адрес интерфейса и проксирует `/api` и `/docs` на backend.

## Данные и конфиденциальность

- Фото и созданные сервером файлы хранятся локально в `uploads/` и `generated/`.
- Пароли профилей хранятся как Argon2-хеши в `data/accounts.json`. Этот локальный файл не следует добавлять в Git.
- Сессии живут в памяти backend и прекращаются после его перезапуска.
- Библиотека GLB и настройки редактора находятся в хранилище текущего браузера; синхронизации с облаком нет.
- Локальная модель TripoSR и её Python-окружение не входят в Git.

## Rust-трассировщик

Создать четыре PPM-сцены размером 800×600:

```bash
cargo run -- render-scenes
```

Результаты появятся в `renders/`. Интерактивный рендер также доступен в панели **Render** приложения. Описание алгоритмов: [docs/ray-tracing.md](docs/ray-tracing.md).

## Структура проекта

```text
src/                 Rust API, геометрия, математика и рендерер
frontend/            TypeScript-интерфейс и 3D-редактор
ai/                  Вспомогательные скрипты интеграции TripoSR
scripts/             Установка локальной AI-модели
docs/                Инструкции и описание архитектуры
```
