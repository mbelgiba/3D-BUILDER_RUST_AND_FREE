# RT Studio

RT Studio — учебное веб-приложение на Rust для загрузки изображения, локального создания приблизительной 3D-модели с TripoSR, просмотра GLB в браузере и рендера демонстрационных сцен собственным трассировщиком лучей.

## Возможности

- Rust/Axum backend и API загрузки JPEG/PNG.
- Проверка реального формата изображения, лимит 10 МБ и 25 мегапикселей.
- Локальная интеграция с открытой моделью TripoSR; API-ключ и плата за запросы не нужны.
- Просмотрщик Three.js с орбитой камеры, трансформациями, материалом и светом.
- Трассировщик лучей на Rust: диффузное освещение Ламберта, фоновый свет, жёсткие тени и выдача P3 PPM.
- Четыре демонстрационные сцены в `renders/`.

Трассировщик рендерит встроенные сцены из примитивов. Он пока не импортирует геометрию AI-модели GLB.

## Требования

Rust/Cargo, Node.js 20 или новее, npm и браузер с поддержкой WebGL. Для AI-генерации нужны Python 3.8+, PyTorch и TripoSR. Установщик выбирает PyTorch для NVIDIA GPU или CPU-вариант. Веса модели скачиваются отдельно при первой генерации; на CPU она может быть медленной. Просмотр демонстрационной сцены и Rust-рендер доступны без AI.

Проверьте установленные версии:

```bash
rustc --version
cargo --version
node --version
npm --version
```

## Полный запуск проекта

Все команды backend выполняются из корня репозитория.

1. Установите frontend-зависимости и соберите веб-интерфейс:

   ```bash
   cd frontend
   npm install --ignore-scripts
   npm run build
   cd ..
   ```

2. Один раз установите локальную AI-модель (требуется интернет для зависимостей и весов):

   ```bash
   bash scripts/setup-local-ai.sh
   ```

   Установка занимает место на диске. Папка модели и Python-окружение исключены из Git. В `.env` можно переопределить `TRIPOSR_DIR`, `TRIPOSR_PYTHON` и `TRIPOSR_DEVICE`; шаблон лежит в `.env.example`.

3. Запустите Rust-сервер:

   ```bash
   cargo run
   ```

4. Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000). Проверка API: [http://127.0.0.1:3000/api/health](http://127.0.0.1:3000/api/health).

Более подробная инструкция и решение типичных ошибок: [docs/index.md](docs/index.md).

### Разработка интерфейса через Vite

Оставьте `cargo run` работающим в одном терминале. Во втором выполните:

```bash
cd frontend
npm run dev
```

Откройте адрес, указанный Vite (по умолчанию `http://127.0.0.1:5173`). Запросы `/api` и `/docs` будут проксироваться в Rust backend на порт 3000.

## Использование генерации AI

В веб-приложении загрузите чёткое JPEG/PNG-изображение одного предмета и нажмите **Create 3D model**. Rust проверит файл и запустит TripoSR на этой машине. После завершения GLB откроется в просмотрщике. Модель бесплатная и запускается локально; облачный API и ключи не используются.

Если TripoSR не установлен, генерация недоступна, но демонстрационная сцена и трассировщик работают. По одному снимку нельзя точно восстановить скрытые стороны, результат будет приблизительным. Подробности: [docs/ai-pipeline.md](docs/ai-pipeline.md).

## Управление просмотрщиком

- Левая кнопка мыши — вращать камеру; колесо — приближать/отдалять.
- Правая кнопка мыши или Shift + перетаскивание — панорамировать.
- Вкладки **Object**, **Lighting**, **Material**, **Camera** управляют предпросмотром.
- Кнопки над сценой переключают сетку и оси, сбрасывают камеру и включают полноэкранный режим.
- Панель **Render** запускает Rust-рендер одной из встроенных сцен.

## Трассировщик лучей

Создать изображения четырёх сцен размером 800×600:

```bash
cargo run -- render-scenes
```

Результаты сохраняются в `renders/`. В интерфейсе можно выбрать один из четырёх примитивных наборов и разрешение 400×300, 800×600 или 1200×900. Файлы `.ppm` имеют текстовый формат P3. Подробности алгоритмов: [docs/ray-tracing.md](docs/ray-tracing.md).
